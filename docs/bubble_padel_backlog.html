1.4 Rate Limiting nas Rotas Públicas P1 DEV 4h
Dependências: Nenhuma
Proteger rotas públicas (inscrição, listagem de torneios) contra spam e abuso com rate limiting por IP. Usar express-rate-limit.
Arquivos afetados
  • backend: middlewares/rateLimiter.ts (CREATE)
  • backend: index.ts ou app.ts (MODIFY)
▸ Requisitos detalhados
  1. Instalar express-rate-limit
  2. Rate limiter geral: 100 req/min por IP em todas as rotas
  3. Rate limiter específico para POST /api/public/tournaments/:id/register: 5 inscrições/hora por IP
  4. Resposta 429 com mensagem: "Muitas requisições. Tente novamente em alguns minutos."
  5. Whitelist para IPs do Railway (health checks)
Critérios de aceite
  • Inscrição retorna 429 após 5 tentativas em 1h do mesmo IP
  • Mensagem de erro em português amigável
  • Rotas autenticadas (clube) não afetadas pelo rate limiter público
1.5 ONGOING Automático por Data/Hora P1 DEV 6h
Dependências: Nenhuma
Torneio muda automaticamente para ONGOING quando a data/hora do primeiro jogo agendado chega — sem o clube precisar clicar manualmente. Implementar via cron job no backend.
Arquivos afetados
  • backend: jobs/statusSync.ts (CREATE)
  • backend: index.ts (MODIFY — registrar cron)
▸ Requisitos detalhados
  1. Instalar node-cron
  2. Cron job a cada 15 minutos: verificar torneios com status CLOSED ou PUBLISHED
  3. Para cada torneio, buscar o schedule mais antigo: SELECT MIN(date + time) FROM schedules JOIN matches
  4. Se hora atual ≥ hora do primeiro jogo E status ∈ [CLOSED, PUBLISHED] → atualizar para ONGOING
  5. Log das transições automáticas para debug
  6. Endpoint manual POST /api/tournaments/:id/sync-status já existente — reutilizar lógica
Critérios de aceite
  • Torneio muda para ONGOING automaticamente na hora do primeiro jogo
  • Cron roda a cada 15 minutos sem impactar performance
  • Somente torneios com schedules gerados são elegíveis
  • Log registra cada transição automática
Riscos: Railway pode reiniciar o processo e perder o cron. Verificar se node-cron sobrevive a restarts no Railway ou usar alternativa (agenda, bull).
